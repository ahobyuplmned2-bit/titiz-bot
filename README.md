# بوت Titiz الذكي 🤖

**Titiz موظفتك الذكية نرد على جميع طلباتكم 24 ساعة**

نظام متقدم لبوت WhatsApp متكامل مع نظام السلة والطلبات والدفع وقاعدة بيانات حقيقية.

---

## المميزات الرئيسية ✨

### 1. **نظام المنتجات المتقدم**
- إدارة كاملة للمنتجات مع الصور والأوصاف
- بحث ذكي عن المنتجات
- دعم الكلمات المفتاحية
- إدارة المخزون والكميات

### 2. **نظام السلة والطلبات**
- إضافة/حذف المنتجات من السلة
- تحديث الكميات
- عرض ملخص السلة
- إنشاء طلبات تلقائية

### 3. **نظام الدفع المتكامل**
- الدفع عند الاستلام
- التحويل المسبق مع إثبات الدفع
- تأكيد الدفع من الإدارة
- حسابات تحويل متعددة

### 4. **إدارة العملاء**
- حفظ بيانات العملاء
- تتبع الطلبات
- سجل المشتريات
- إحصائيات العملاء

### 5. **لوحة الإدارة**
- أوامر إدارية متقدمة
- إدارة الطلبات والحالات
- إدارة المنتجات
- عرض الإحصائيات

### 6. **تجربة المستخدم المحسنة**
- واجهة أزرار تفاعلية
- مؤشرات الكتابة
- تأخير طبيعي في الردود
- رسائل واضحة وودية

- Python 3.8+
- Flask
- SQLite (للتطوير) أو PostgreSQL (للإنتاج)
- حساب WhatsApp Business
- توكن WhatsApp Cloud API

## التثبيت والإعداد 🚀

### 1. استنساخ المستودع
```bash
git clone https://github.com/ahobyuplmned2-bit/titiz-bot.git
cd titiz-bot
```

### 2. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 3. إعداد المتغيرات البيئية
```bash
cp .env.example .env
# ثم عدّل .env بالقيم الصحيحة
```

### 4. تشغيل التطبيق
```bash
python app.py
```

التطبيق سيعمل على `http://localhost:10000`

## أوامر العملاء 💬

### التصفح والبحث
- **تصفح** - عرض جميع المنتجات
- **البحث عن [اسم]** - البحث عن منتج
- **[اسم المنتج]** - عرض تفاصيل المنتج

### السلة والطلبات
- **السلة** - عرض السلة الحالية
- **اضف** - إضافة المنتج الأخير إلى السلة
- **اكمل الطلب** - إكمال الطلب
- **فرغ السلة** - حذف جميع المنتجات

### الدفع والمعلومات
- **الدفع** - عرض طرق الدفع
- **التواصل** - معلومات التواصل
- **القائمة** - عرض القائمة الرئيسية

---

## أوامر الإدارة 👨‍💼

**ملاحظة:** أوامر الإدارة تعمل فقط لأرقام الإدارة المصرح لهم

### الطلبات
```
الطلبات                          # عرض جميع الطلبات
تفاصيل [رقم الطلب]              # عرض تفاصيل طلب
حالة [رقم] [الحالة]             # تحديث حالة الطلب
تأكيد دفع [رقم الطلب]            # تأكيد دفع التحويل
```

### المنتجات
```
المنتجات                         # عرض جميع المنتجات
اضف منتج [الاسم] [السعر] [الوصف]  # إضافة منتج جديد
```

### الإحصائيات
```
إحصائيات                         # عرض الإحصائيات العامة
```

## حالات الطلب 📊

| الحالة | الوصف |
|--------|-------|
| جديد | طلب جديد تم إنشاؤه |
| بانتظار مراجعة الدفع | في انتظار تأكيد التحويل |
| تم الدفع | تم تأكيد الدفع |
| جاري التجهيز | الطلب قيد التجهيز |
| تم الشحن | الطلب تم شحنه |
| تم التسليم | الطلب تم تسليمه |
| ملغي | الطلب تم إلغاؤه |
